# Голосовой ассистент Echo

Echo — это минималистичный голосовой ассистент для Windows, работающий по горячей клавише. Он обеспечивает быстрый перевод речи в аккуратно отредактированный текст непосредственно в активном поле ввода с использованием Groq API.

Если вам понравился этот проект, пожалуйста, поставьте звезду репозиторию.

## Возможности

- **Режим диктовки**: Вставляет распознанную речь напрямую в активное текстовое поле. Автоматически исправляет пунктуацию, грамматику, удаляет слова-паразиты и адаптирует произнесенный технический сленг на русском языке в правильное английское написание (например, «экзешник» превращается в «.exe», «питон» — в «Python»).
- **Поддержка нескольких мониторов**: Отображает лаконичный визуальный индикатор записи и обработки звука в нижней центральной части того экрана, на котором в данный момент находится курсор мыши.
- **Интеграция с системным треем**: Работает в фоновом режиме, сворачиваясь в трей, откуда можно открыть панель управления с настройками и логами в реальном времени.
- **Автозапуск при старте системы**: В настройках можно включить запуск Echo вместе с Windows. Запись вносится в реестр пользователя (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`), что исключает необходимость запуска приложения от имени администратора.

## Принцип работы

Приложение работает в виде двухэтапного пайплайна:

1. **Распознавание речи (STT)**: При зажатии горячей клавиши аудио записывается через библиотеку `sounddevice` с частотой 16000 Гц. После отпускания клавиш громкость записи нормализуется (пиковое значение выравнивается до 0.9 для улучшения качества распознавания), сохраняется в стандартный 16-битный PCM WAV и отправляется на Groq Whisper API (`whisper-large-v3-turbo`). Для повышения точности распознавания Whisper передается контекстный промпт с подсказками технических терминов и сокращений.
2. **Обработка текста (LLM)**: Распознанный текст передается текстовой модели (например, `llama-3.3-70b-versatile`) вместе со специализированным системным промптом редактора. Результат копируется в буфер обмена и вставляется в активное приложение.

## Системные промпты и кастомизация

Системный промпт управляет тем, как именно ассистент форматирует надиктованный текст. Он находится в файле `groq_client.py` внутри функции `process_audio_pipeline`. Вы можете открыть этот файл и изменить промпт под свои нужды:

- **Промпт диктовки (Dictation Prompt)**: Инструктирует модель выступать в роли строгого текстового редактора. Она расставляет знаки препинания, удаляет запинки (например, «эээ», «ну»), заменяет русскоязычную запись терминов на английский оригинал, структурирует перечисления списками, но не отвечает на вопросы и не меняет исходный порядок мыслей.

## Получение API-ключ Groq

Echo использует облачный API Groq для обеспечения минимальной задержки при распознавании речи и генерации текста. Вы можете бесплатно получить API-ключ:

1. Зарегистрируйтесь на сайте [Groq Console](https://console.groq.com/).
2. Перейдите в раздел **API Keys** в левом боковом меню.
3. Нажмите кнопку **Create API Key**, укажите имя ключа и скопируйте его.
4. Вставьте скопированный ключ в поле настройки API Key в панели управления Echo.

## Требования

Для запуска приложения требуется Python версии 3.8+ на операционной системе Windows.

Системные зависимости (автоматически устанавливаются из requirements.txt):
- PyQt6
- sounddevice
- soundfile
- keyboard
- pyperclip
- groq
- numpy
- pyautogui

Для записи звука необходим микрофон. Для работы функций распознавания и обработки текста требуются стабильное интернет-соединение и API-ключ Groq.

## Установка

1. Склонируйте репозиторий с проектом на свой компьютер.
2. Рекомендуется создать и активировать виртуальное окружение:
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
3. Установите необходимые библиотеки:
   ```powershell
   pip install -r requirements.txt
   ```

## Запуск приложения

Запуск голосового ассистента в режиме разработки:
```powershell
python main.py
```

После запуска:
- Дважды кликните по иконке приложения в трее Windows, чтобы открыть панель управления.
- Укажите ваш API-ключ Groq в конфигурации и сохраните настройки.

## Горячие клавиши

- **Диктовка**: Удерживайте `Ctrl + Windows` во время речи. После отпускания клавиш начнется обработка и вставка набранного текста.
- **Панель управления**: Открывается двойным кликом по иконке в трее.

## Сборка в исполняемый файл (.exe)

Чтобы собрать приложение в единый исполняемый файл для Windows, который будет работать без окна консоли и использовать встроенную минималистичную иконку звуковой волны, установите PyInstaller и выполните сборку:

```powershell
pip install pyinstaller
pyinstaller --noconsole --onefile --name="Echo" --icon=icon.ico --add-data "icon.png;." main.py
```

Готовый файл `Echo.exe` появится в директории `dist/`.
