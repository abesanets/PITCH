# Голосовой ассистент PITCH

PITCH — это минималистичный голосовой ассистент для Windows, работающий по горячей клавише. Он обеспечивает быстрый перевод речи в аккуратно отредактированный текст непосредственно в активном поле ввода с использованием Groq API.

Если вам понравился этот проект, пожалуйста, поставьте звезду репозиторию.

## Возможности

- **Режим диктовки**: Вставляет распознанную речь напрямую в активное текстовое поле. Автоматически исправляет пунктуацию, грамматику, удаляет слова-паразиты и адаптирует произнесенный технический сленг на русском языке в правильное английское написание (например, «экзешник» превращается в «.exe», «питон» — в «Python»).
- **Поддержка нескольких мониторов**: Отображает лаконичный визуальный индикатор записи и обработки звука в нижней центральной части того экрана, на котором в данный момент находится курсор мыши.
- **Интеграция с системным треем**: Работает в фоновом режиме, сворачиваясь в трей, откуда можно открыть панель управления с настройками и логами в реальном времени.
- **Автозапуск при старте системы**: В настройках можно включить запуск PITCH вместе с Windows. Запись вносится в реестр пользователя (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`), что исключает необходимость запуска приложения от имени администратора.
- **История диктовок**: Сохраняет до 100 последних записей с подробной статистикой (модели, задержки, количество слов/символов). История доступна в панели управления с возможностью просмотра деталей.
- **Настраиваемый визуализатор**: Три стиля визуализации звука (волны, столбцы, скроллящийся эквалайзер) с 8 цветовыми пресетами (Mono, Ocean, Aurora, Neon, Sunset, Lavender, Rose, Forest) и возможностью создания собственного пресета через color picker.
- **Темная и светлая темы**: Полная поддержка двух тем оформления для панели управления и визуализатора.
- **Гибкая настройка моделей**: Возможность выбора различных моделей Groq для распознавания речи (Whisper) и обработки текста (Llama, Mistral и др.).

## Принцип работы

Приложение работает в виде двухэтапного пайплайна:

1. **Распознавание речи (STT)**: При зажатии горячей клавиши аудио записывается через библиотеку `sounddevice` с частотой 16000 Гц. После отпускания клавиш громкость записи нормализуется (пиковое значение выравнивается до 0.9 для улучшения качества распознавания), сохраняется в стандартный 16-битный PCM WAV и отправляется на Groq Whisper API (`whisper-large-v3-turbo`). Для повышения точности распознавания Whisper передается контекстный промпт с подсказками технических терминов и сокращений.
2. **Обработка текста (LLM)**: Распознанный текст передается текстовой модели (по умолчанию `meta-llama/llama-4-scout-17b-16e-instruct`) вместе со специализированным системным промптом редактора. Результат копируется в буфер обмена и вставляется в активное приложение.
3. **Фоновый прогрев**: При запуске приложения Groq клиент прогревается в фоновом режиме для уменьшения задержки при первой диктовке.
4. **Сохранение истории**: Каждая диктовка сохраняется в историю с метаданными (временная метка, модели, задержки, статистика текста).

## Системные промпты и кастомизация

Системный промпт управляет тем, как именно ассистент форматирует надиктованный текст. Он находится в файле `groq_client.py` внутри функции `process_audio_pipeline`. Вы можете открыть этот файл и изменить промпт под свои нужды:

- **Промпт диктовки (Dictation Prompt)**: Инструктирует модель выступать в роли строгого текстового редактора. Она расставляет знаки препинания, удаляет запинки (например, «эээ», «ну»), заменяет русскоязычную запись терминов на английский оригинал, структурирует перечисления списками, но не отвечает на вопросы и не меняет исходный порядок мыслей.

## Панель управления (Dashboard)

Панель управления предоставляет удобный интерфейс для настройки всех параметров приложения:

- **Вкладка Settings**: Настройка API-ключа, горячей клавиши, модели текста, автозапуска, темы оформления
- **Вкладка Visualizer**: Выбор стиля визуализатора (wave/bars/scroll), цветового пресета, размера, чувствительности, а также создание собственного цветового пресета
- **Вкладка History**: Просмотр истории диктовок с детализацией каждой записи, статистика производительности
- **Вкладка Logs**: Мониторинг логов приложения в реальном времени

Панель управления имеет современный дизайн с нативными скругленными углами Windows 11 (через DWM API), перетаскиванием за заголовок и кастомными элементами управления окном.

## Получение API-ключ Groq

PITCH использует облачный API Groq для обеспечения минимальной задержки при распознавании речи и генерации текста. Вы можете бесплатно получить API-ключ:

1. Зарегистрируйтесь на сайте [Groq Console](https://console.groq.com/).
2. Перейдите в раздел **API Keys** в левом боковом меню.
3. Нажмите кнопку **Create API Key**, укажите имя ключа и скопируйте его.
4. Вставьте скопированный ключ в поле настройки API Key в панели управления PITCH.

## Требования

Для запуска приложения требуется Python версии 3.8+ на операционной системе Windows.

Системные зависимости (автоматически устанавливаются из requirements.txt):
- PyQt6 — графический интерфейс
- sounddevice — запись аудио
- soundfile — работа с WAV файлами
- keyboard — мониторинг горячих клавиш
- pyperclip — работа с буфером обмена
- groq — API клиент для Groq
- numpy — обработка аудио данных
- pyautogui — автоматизация ввода
- pywin32 — работа с реестром Windows (для автозапуска)

Для записи звука необходим микрофон. Для работы функций распознавания и обработки текста требуются стабильное интернет-соединение и API-ключ Groq.

## Установка

1. Склонируйте репозиторий с проектом на свой компьютер.
2. Рекомендуется создать и активировать виртуальное окружение:
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
3. Установите необходимые библиотеки:
   ```powershell
   pip install -r requirements.txt
   ```

## Запуск приложения

Запуск голосового ассистента в режиме разработки:
```powershell
python main.py
```

После запуска:
- Дважды кликните по иконке приложения в трее Windows, чтобы открыть панель управления.
- Укажите ваш API-ключ Groq в конфигурации и сохраните настройки.

## Горячие клавиши

- **Диктовка**: Удерживайте `Ctrl + Windows` во время речи. После отпускания клавиш начнется обработка и вставка набранного текста.
- **Панель управления**: Открывается двойным кликом по иконке в трее.

## Настройки визуализатора

Визуализатор предлагает широкие возможности кастомизации:

### Стили визуализации
- **Wave**: Плавные синусоидальные волны с эффектом глубины
- **Bars**: Классический столбчатый эквалайзер
- **Scroll**: Скроллящийся эквалайзер с движущимися элементами

### Цветовые пресеты
- **Mono** (по умолчанию): Минималистичный монохромный стиль
- **Ocean**: Голубые и синие оттенки океана
- **Aurora**: Зелено-голубые тона северного сияния
- **Neon**: Яркие розово-фиолетовые неоновые цвета
- **Sunset**: Теплые оранжево-красные тона заката
- **Lavender**: Мягкие фиолетовые оттенки лаванды
- **Rose**: Насыщенные розовые тона
- **Forest**: Природные зеленые цвета леса
- **Custom**: Создание собственного пресета через встроенный color picker

### Размеры и чувствительность
Пять размеров визуализатора (XS, Small, Medium, Large, XL) и настраиваемая чувствительность (0.5 - 2.0) для точной подстройки под ваш микрофон.

## Сборка в исполняемый файл (.exe)

Чтобы собрать приложение в единый исполняемый файл для Windows, который будет работать без окна консоли и использовать встроенную минималистичную иконку звуковой волны, установите PyInstaller и выполните сборку:

```powershell
pip install pyinstaller
pyinstaller --noconsole --onefile --name="PITCH" --icon=icon.ico --add-data "assets/p.jpeg;assets" --add-data "assets/white_pitch_on_black.jpeg;assets" --add-data "assets/black_pitch_on_white.jpeg;assets" main.py
```

Готовый файл `PITCH.exe` появится в директории `dist/`.

## Архитектура

Приложение построено на базе PyQt6 и использует многопоточную архитектуру:

- **Главный поток (GUI)**: Обработка UI событий, отрисовка визуализатора
- **Поток мониторинга**: Отслеживание горячих клавиш в фоновом режиме
- **Поток обработки**: Асинхронная обработка аудио через Groq API
- **Сигналы Qt**: Безопасная коммуникация между потоками для обновления UI

Ключевые особенности реализации:
- Frameless окно с нативными скругленными углами Windows 11 (DWM API)
- Модульная архитектура UI с разделением на компоненты
- Система тем с автоматическим применением к всем элементам
- Background warmup Groq клиента для уменьшения задержки
- Автоматическое логирование stdout/stderr в файл и UI
